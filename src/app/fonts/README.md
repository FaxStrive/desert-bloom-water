# Vendored web fonts

The latin subset of every font family `styles/*/style.json` can name, as woff2.
Generated by `bin/vendor-seed-fonts.mjs`; provenance and licensing for each
file are in `fonts.json`. Do not hand edit either, re-run the script.

## Why these are on disk instead of coming from Google

`next/font/google` fetches `https://fonts.googleapis.com/css2` during the build
and pulls a file extension off every font url in the response, with no null
guard:

    next/dist/compiled/@next/font/dist/google/loader.js:122
      const ext = /\.(woff|woff2|eot|ttf|otf)$/.exec(googleFontFileUrl)[1]

Google normally returns urls ending in `.woff2`. It intermittently returns the
extensionless form instead, `https://fonts.gstatic.com/l/font?kit=...`, and on
those responses `.exec()` returns null and the build dies:

    src/app/fonts.ts
    An error occurred in `next/font`.
    TypeError: Cannot read properties of null (reading '1')
    > Build failed because of webpack errors

Measured on the build machine on 2026-09-30: 1 response in roughly 50 came back
extensionless. Two cold builds of the same unmodified directory, minutes apart,
gave exit 0 and then that TypeError. So it is an upstream coin flip, not
something a build can be trusted to retry past, and it is not a network outage
either: the CSS fetch returns 200 both times.

Self-hosting removes the build-time network call, which also puts the fonts
under the same rule `bin/assert-local-assets` applies to every other asset a
client site ships: we serve our own media, we do not hotlink a third party.

## Shape of the files

One file per family where Google publishes a variable font, carrying the whole
weight range, so a style asking for 400/500/600 costs one request rather than
three. Families with no variable version (Barlow Condensed) get one static file
per weight the styles actually ask for.

Total library is about 243 KB across 9 files, but a build only emits the one or
two families its style names. `next/font/local` fingerprints those into
`/_next/static/media` with immutable cache headers and leaves the rest out, so
a site ships roughly 22 to 85 KB of font.

All families are OFL-1.1, which permits self-hosting.
